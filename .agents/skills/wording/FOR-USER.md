# 界面文案（终端用户）

读者不写代码，可能在赶时间，也可能第一次打开这块界面。
这一份只写界面与 agent 交代特有的部分；语域与词表见 [VOICE.md](VOICE.md)、[TERMS.md](TERMS.md)。

## 四问

1. 用户读完知道下一步做什么吗？
2. 名词在界面上找得到吗？
3. 有口语词、内部词、套近乎吗？
4. 把技术细节拿掉，这句话还成立吗？

## 场景与字数

| 场景 | 字数上限 | 必须写清 |
|---|---|---|
| 模块标题 | ≤12 汉字 | 和卡内容一致的名词短语 |
| 空态 | 1 句 + 可选提示 | 「没有什么」+ 怎么才有 |
| 加载 | ≤8 字 | 不解释、不道歉 |
| 阻断 | 标题 1 句 + 提示 1 句 + 1 动作 | 缺什么 / 为什么 / 去哪 |
| 行内提示 | ≤20 字 | 一条事实 |
| 按钮 | 动词 + 对象，≤6 字 | 点了会发生什么（「安装到工作台」） |
| 配置 | 标签 ≤8，说明 ≤30 | 默认值 + 影响 |
| 审批问句 | ≤40 字；装配 ≤108 | 对象 + 动作 + 「允许吗」 |
| 审批明细 | ≤20 字 / 行 | 一行一个事实 |
| agent 交代 | ≤2 句 | 结论 + 位置 + 下一步 |
| 启动检查 | 界面句 1 句 + 技术细节 | 哪一步没过 + 点哪 |
| 市场 / 重启状态 | 状态词 + 原因 + 动作 | 现在怎样 + 为什么 + 能做什么 |
| 调试 / 录制底栏 | 状态 + 一颗键 | 现在在做什么 |
| a11y / placeholder | 动作 + 对象 | 不带「按钮 / 输入框」这类角色词 |

审批那三个数字来自 ADR-0065；其余是本文口径，可调。

## 句式

| 场景 | 句式 | 例 |
|---|---|---|
| 空态 | 「还没有<对象>。」+「如何产生」 | 这个工作区还没有模块。到模块市场安装，或让 agent 添加。 |
| 阻断 | 「无法<动作>：<原因>。」+「下一步」 | 无法连接后台服务。请重启工作台后重试。 |
| 错误 | 「<对象><动作>失败：<原因>。」+「下一步」 | 更新失败：没有写入权限。请检查权限后重试。 |
| 审批 | 对象 + 动作 + 影响 + 「允许吗」 | 允许安装脚本在这台机器上运行吗？ |
| 状态 | 「<对象><状态>」 | 长任务运行中 / 模块已安装 / 更新失败 |
| 按钮 | 动词 + 对象 | 安装 / 卸载 / 重试 / 查看详情 |
| 配置 | 标签 + 一句说明 + 默认 / 影响 | 默认开启：新项目自动启用该模块。 |
| agent 交代 | 结论 + 位置 + 下一步 | 已更新 12 条界面文案，集中在模块市场。下一步运行 `check:copy`。 |

## 界面句 + 技术细节

- **界面句**：给用户，不含错误码、路径、堆栈、内部词。
- **技术细节**：进 `detail` / 折叠区 / 日志，原样保留。

两条标准：

1. 只看界面句：用户知道发生了什么、下一步做什么。
2. 只看技术细节：开发能定位。

安装命令是特例：界面句说「装什么、为什么」，下一行原样命令；命令不翻译、不拆成散文。

## zh / en

- 两语都写；键带 `<unit>.`；两种语言同构。
- 英文重写，不直译；长度 ≤ 中文 ×3。
- 中文全角标点，英文 sentence case；不用感叹号。
- 同一条规则管两语，不因为英文就放宽。

## 验收

1. 真界面五态各看一遍；两语各看一遍。
2. 逐句过四问。
3. 只看界面句，走一遍主流程。
4. 审批屏对黄金屏；模块跑 `check --only cards`；全量跑 `check:copy`。
