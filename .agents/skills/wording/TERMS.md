# 词表：一个概念一个词

写文案前先查这张表；表里没有的概念，先补表，再写。

## 动词

用：安装 / 卸载 / 更新 / 启动 / 重启 / 运行 / 停止 / 打开 / 查看 / 复制 / 重试 / 保存 / 删除 / 添加 / 移除 / 启用 / 停用 / 批准 / 允许 / 取消。

不写：装上 / 装好 / 卸掉 / 换上 / 换掉 / 点进去 / 点一下 / 跑一遍 / 跑一次 / 弄 / 搞 / 造 / 收工 / 上板 / 点头 / 粘到 / 自己动手。

## 状态

写：未安装 / 已安装 / 可更新 / 更新中 / 更新失败 / 运行中 / 已完成 / 待查看 / 等待批准 / 已暂停 / 不可用 / 未就绪。

不写：在跑 / 跑完 / 跑完没看 / 没在跑 / 起不来 / 没起来 / 活了 / 挂了 / 崩了 / 卡住。

## 双向禁词

### 内部词（不出现界面句与 agent 交代）

profile / adapter / schema / payload / bundle / patch / stderr / probe / unit / daemon / opencli / 投影 / 事实 / 宿主 / 套件 / 索引源 / 适配器集合 / 体检 / 模块 id / 产物目录 / 上下文 / 装配 / 收窄 / 落盘 / 兜底。

写法：换成界面词；换不了就移到技术细节（detail / 折叠区 / 日志）。日志与 CLI 可以用技术词，但要与界面词同源，且可 grep。

### 口语词（不出现界面句与 agent 交代）

这一下 / 这一跳 / 点进去 / 点头 / 上板 / 收工 / 在跑 / 跑完 / 起不来 / 装上 / 装好 / 卸掉 / 换上 / 弄 / 搞 / 造 / 就好 / 就行 / 帮你 / 替你 / 不用你点 / 粘到 / 自己动手 / 咱们 / 我们。

写法：查上面的动词与状态表；没有就补表。

### 例外

- 日志、CLI、堆栈、detail：技术词可用，但同一概念必须与界面词同源。
- 高级设置页：术语可用，首次出现必须给界面词或一句解释。
- 命令、包名、参数名：原样，不翻译。

## 登记流程

1. 新概念出现：先加「内部词 → 界面词」一行，再写文案。
2. 界面词必须能在界面上找到；找不到，说明这个概念还没落地。
3. 同一概念只留一个词；旧词进禁词表。
