# 更新日志

按 [Conventional Commits](https://www.conventionalcommits.org/) 记。提交信息在门禁里被检查，
不合规的进不来。

## 0.3.11

首个公开版本。仓库从内部仓整理成公开仓，这一版把该脱的都脱了，该守的都写进了门禁。

- **公开**：去掉内部模块与私有源，仓库地址换成公开那份；`private-docs` 作为私有子仓单独挂着，
  公开构建与门禁都不需要它
- **零注释**：全仓代码不留注释，规则落到门禁里；只有公开入口的成员允许贴导出的 JSDoc，
  该面的判定按「公开入口可达的文件」算
- **门禁**：一条链跑完类型、lint、覆盖率、架构红线、文档、运行时隔离、接线自检、模块判据、
  发布产物；链首先 build，干净 clone 上也能一次跑通
- **提交**：接入 commitlint 与提交钩子，提交信息不合规当场被拒
- **文档**：重写用户视角的 README，补上 Desktop 装法；架构文档按现有代码重写；
  每个包各自有 README
- **文档站**：你现在看的这个站点，Pagoda CLI 搭的

## 再往前
