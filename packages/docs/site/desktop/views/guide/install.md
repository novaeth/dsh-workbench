# 安装

工作台是 DeepSeek Harness 的一个插件，安装在 **Desktop（DeepSeek Harness.app）** 中。
不需要另开进程，也不需要输入命令。

## 在 Desktop 中安装

1. 打开 Desktop 侧栏 **Plugins → Add plugin**
2. 填 `@dsh-workbench/core`，**Install → Enable now**
3. 重新打开窗口 / 刷新

安装后，模块市场、看板与设置都会出现；会话、项目与附件沿用 Desktop 现有的那一份，不需要迁移。
Desktop 里页面调试不可用：站点只读探索、录制、面板与状态照旧；不带站点地址的看 / 动会被拒绝并说明下一步。

## 安装后第一次打开

第一次打开时会先出现「准备工作台」这一屏，并依次执行启动检查（共 6 步）：检查运行环境、
检查运行时、安装后台工具、连接浏览器、检查 DIY 模式、连上站点。opencli 的隔离运行时放在
`~/.dsh/workbench/opencli`，**不改动**你本机的 `~/.opencli`。启动检查不需要你操作；如果安装失败
（无网络或安装源不可达），这一屏会给出原因和一条可以直接复制的命令，这条命令需要在终端里运行。

### 安装一次 OpenCLI 浏览器扩展

面板（以及网页浏览、录制这类浏览器工具）读取的是你浏览器里的登录状态，所以还需要在浏览器里安装一次扩展：

1. 用 Chrome / Edge / Brave / Chromium / Vivaldi 打开
   [OpenCLI（Chrome 应用商店）](https://chromewebstore.google.com/detail/opencli/ildkmabpimmkaediidaifkhjpohdnifk)，选择安装
2. 到扩展页确认它已启用；用你平时登录这些平台的浏览器账号，保持浏览器打开（不需要停在某个页面）
3. 回到「准备工作台」这一屏选择「重试」

启动检查里「连接浏览器」显示已连接，说明配置成功。Desktop 的这一屏还提供「打开浏览器」按钮：
点击后会打开上次承载扩展的那个浏览器（未记录时使用 Chrome），打开后自动复检。

### 启动检查未通过也能使用

浏览器没有连接也不影响进入工作台，可以选择「先进入工作台」；但在连接成功之前，依赖登录状态的面板都取不到数据。
平台登录按模块提示进行，每个平台登录一次。

启动检查提示连接了多个浏览器账号时，请先选择一个默认账号：页面上会给出可以直接复制的命令，
按页面提示操作。每个浏览器账号各有一个扩展实例，工作台不会自行猜测。

## 卸载

- 在 Desktop 的插件页移除工作台。
- 浏览器里的 OpenCLI 扩展不会随工作台卸载；不再使用时，到浏览器的扩展页移除。
