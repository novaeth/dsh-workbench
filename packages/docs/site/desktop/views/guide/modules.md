# 面板与模块

右侧那块面板的能力不是内置的，是**模块**。工作台本身不带业务模块 —— 装什么有什么。

## 模块是什么

一个独立的小包，声明自己占哪张卡、调哪些工具、读哪份状态。装上之后右侧多一张卡片，
卸掉就没了。它可以是别人发布的，也可以是 agent 当场给你做的。

## 装 / 升 / 卸

在「工作台模块市场」里点就行：装、升、卸都在那一页，装完即用，不用重启整个工作台。

不方便点的时候，直接说：

> 帮我装一下缺陷面板

agent 会走工具装、启用、刷新，失败会说明卡在哪一步。

## DIY：让 agent 现场做一个

不想找现成的、或者要的面板市面上没有，就开 DIY 模式。agent 会在工作区里建骨架、
写代码、跑判据、装上去。你不用先学一套框架；写得对不对由门禁兜。

骨架、判据、模板都在仓库的 `packages/module-tools`，模块 DIY 的共用口径只有一份，
住在 `packages/workbench/skills/workbench-module-diy/`，不在文档里另抄。

## 一条硬规矩

:::warning 界面只读，写入只走 agent 工具
面板里出现写接口就是设计错了。面板负责把状态摆清楚；改状态这件事交回给 agent，
这样谁改的、怎么改的，都在对话里有据可查。
:::

这条不是建议，是判据的一部分：模块的读接口与写接口分开判，越界直接判红。

## 面板长什么样的

- 一张卡片一个视角：缺陷、构建、分析，各自一列
- 空态、加载、失败都有话说，不留白屏
- 需要登录的平台按卡片提示登录，回来点「重试」
