# 数据与设置

一句话：**独立实例是另一套，装进 `dsh web` / Desktop 是这一套。**

| 装法 | 会话 | 设置 | 登录凭据 |
| --- | --- | --- | --- |
| 独立实例 | 自己一份 | 自己一份（`:3081` 的 Settings） | 与 web 共用 |
| 装进 `dsh web` | 沿用当前 | 用 `dsh web` 的设置 | 同一份 |
| Desktop | 沿用 Desktop 的 | 用 Desktop 的设置 | 同一份 |

## 设置在哪

- 独立实例：`:3081` 的 **Settings**。想少配一遍，可以从 `dsh web` 同步已经配好的行。
- 装进 `dsh web` / Desktop：就在各自原来的设置里，工作台不多一个入口。

## 端口与实例

```bash
WORKBENCH_PORT=3091 npx @dsh-workbench/core
npx @dsh-workbench/core --profile wb2
```

`--profile` 决定用哪套数据。两个不同 profile 可以同时跑，互不干扰。

## 备份与清理

工作台的数据都在它自己的目录里，不在你的项目里。想带走：整份拷走；想回到原样：
移除插件 / 停掉实例，再删掉那个目录。它不会碰你的项目文件，也不会碰 `dsh web` 的数据。

:::tip 登录凭据是共用的
共用的是「你已经登录过这个平台」这件事，不是会话内容。所以独立实例里不用重新登录，
但两边对话各自独立。
:::

## 换机器

装一遍、登录一次，然后把你关心的目录拷过去。模块是装出来的，重装一次比拷目录干净。
