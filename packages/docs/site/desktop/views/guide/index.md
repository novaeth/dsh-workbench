## 让面板有东西

<PagodaDocLinkToView view="guide/modules">面板与模块</PagodaDocLinkToView>：面板能力来自模块，安装什么就有什么；没有现成的就让 agent 开启 DIY 现场创建。面板读取的是你浏览器里的登录状态：请先安装 OpenCLI 扩展并保持浏览器打开，再按卡片提示登录。
