# 联动：谁在动、何时变、哪一格变

步骤 3 的参考。实现见 §8。

## 1 触发规则

| 触发 | 面板 |
|---|---|
| agent 读面板这一格 | 该格按最窄切片重读；值与对话一致 |
| agent 读面板外的东西（明细 / 日志 / 子集） | 不变 |
| agent 只预览 | 不变 |
| agent 真写 | 相关格变新值 |
| 用户自按动作 | 该格立即变，原地显示进行中 / 完成 |
| 用户改偏好 | 保存后按新偏好显示 |
| 其他窗口 / 会话改动 | 跟随变，无需刷新 |

一次说清变哪一级：整板 / 一张卡 / 一行。"刷新一下"不合格。只动该动的格，粒度落到"某投影 + 最窄参数"
（`inventory/builds?env=dev`）；否则会整卡重读。

## 2 进行中

- 显示可读的步骤名，不用内部步骤号。
- 要登录：给登录入口；登录后续跑，不重来。
- 失败：卡在哪步、一句原因、原始输出（折叠）、一条可照做的路。
- 不画进度条、不画流程控制台。

中途停止可续：用户说"接着做"即从上次继续。

## 3 "交给 agent"的内容

- 哪一类 + 哪个对象 + 多少（按用户点的那一行，不是全量）。
- 一句"用哪个能力取明细"（agent 打不开面板的 ↗）。
- 不塞明细本身。
- 保持用户点的分类；认不出就报错，不退回全量。

## 4 收起模块

收起 = 该项目内 agent 也失去该能力。收起时说明；收起后能力清单更新，对话显示"能力有更新"；其他项目不受影响。

## 5 不陈旧

覆盖三种：切项目 → 立刻显示新项目；其他窗口 / 会话改动 → 跟随；程序刚更新 → 不因"我比你还新"而不收更新。
允许秒级延迟，但要说明；不得停在旧值等手动刷新。

## 6 联动表（步骤 3 产出）

| 谁在动 | 何时变 | 哪一格 | 看到什么 |
|---|---|---|---|
| agent 读面板这一格 | 读完 | 该格（最窄切片） | 加载态（约半秒）→ 与对话同值 |
| agent 读面板外 | 不变 | — | 对话内结果 |
| agent 预览 | 不变 | — | 对话内"将要做什么" |
| agent 真写 | 完成 | 相关格 | 新值 |
| 用户自按 | 立即 + 完成再更新 | 该格 | 确认条 → 进行中 → 结果 |
| 用户改偏好 | 保存后 | 整卡 | 回看板、数据已换 |
| agent 改面板 / 装卸能力 | 自动 | 增删或顺序，或相关几处 | 界面变化 + "能力有更新" |
| 长任务运行 | 自动推进度 | 卡的进度行 | 到哪步 / 要登录 / 失败原因 |
| 其他窗口 / 程序更新 | 自动 | 同"真写" / 整板 | 同"真写" / 不回旧值 |
| 切项目 / 点刷新 | 立即 | 整板 / 该份 | 新项目 / 转圈后新值 |
| 模块在项目内被收起 | 自动 | 少一张卡 | "能力有更新" |

## 7 读工具对应哪一格

每把读工具回答三句，写进能力清单：

1. 读的数据是面板哪一格？
2. 该格最窄切片是什么（哪个环境哪一列 / 哪档筛选 / 整卡）？
3. 手里这份是否就是该格的值？

| 读的范围 | 面板 |
|---|---|
| 该格范围内 | 该格重读；手里就是该格值时可直接交出（不再重打平台） |
| 面板外（明细 / 日志 / 单条） | 不变 |
| 该格的子集（只读 TODO、更小 limit） | 不变；不得当该格交出（错值）—— 要一致就读全量档 |

## 8 宿主侧实现

四个可选字段。不写 `factsOf` 的模块，面板格不会自己新。

```ts
factsOf: (call) => (call.source === REBUILD_TOOL ? [factOfRoute(HEALTH_ROUTE)] : undefined),
```

- `call.source` = 能力名，`call.args` = 本次参数。返回本次涉及的事实：`[]` = 涉及但无具体事实；
  `undefined` = 与面板无关。
- 事实名用 `factOfRoute('<unit>/<路由>')`（`kit.api.factOfRoute`），不要手拼。读能力也认领；长任务写
  `longTasks.create({ …, facts: () => [factOfRoute(HEALTH_ROUTE)] })`。

```tsx
const rev = useFactRevision(factOfRoute(HEALTH_ROUTE));
const resource = useApiResource(ROUTE, query, rev, {});
```

`useApiResource` 默认订阅 `factOfRoute(route)`；用户自按动作完成后用 `useFactInvalidate()()` 标脏。

```ts
context: { kinds: ['module'], render: async (ref) => `模块 ${ref.parts[0]}：…` },
warmReads: () => [['<unit>', '<target>']],
```

- `context`：把 agent 上下文里的引用渲染成人话；`kinds` 列出识别的类型；形状不对就 `throw`。
- `warmReads`：只给走 opencli 适配器的读。条目是该 opencli 命令的 argv，启动 preflight 先跑一遍。
  本地读盘、browser bridge、直连接口的读不要写。
- `values`：跨单元传值。`values.hand({fact, key}, 值)` / `values.take({fact, key})`。
