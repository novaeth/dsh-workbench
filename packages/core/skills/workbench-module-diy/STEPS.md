# 先分叉，再三步：问什么、产出什么、何时算完

每一步的结果当场写进 `design.json`：`panel` / `states` / `config` / `capabilities` / `linkage` /
`datasource` / `reads[]` / `writes[]` / `acceptance`。`design check` 列出空格。

## 步骤 0 — 一次性还是固化

多步、要等、要重试、要写平台的活，先问一句：

> 这件事是一次性的，还是以后还要按同样步骤跑？我建议 <…>，因为 <…>。

- **一次性**：不建模块，直接用现有工具 / 命令跑；不进下面的三张表，也不写 `design.json`。
- **固化**：继续步骤 1–3；先把「步骤、输入、写到哪、失败停在哪、哪些要点头」写进能力表；实现见 [FLOW.md](FLOW.md)。

只问一次；用户已说过「就这一次 / 以后都要 / 固化」就照办，不追问。

## 步骤 1 — 面板

一次问一组，每组给推荐答案：

- 打开面板第一眼看到什么？拿它做什么决定？
- 哪些事要能自己配？配完看到什么不同？
- 哪些事一定会说给 agent 听？原话是什么？

定四件事：

1. **展示清单**，每条一句人话：这一格是什么 / 一眼得出什么结论 / 点一下去哪。详情、评论、流转、日志不在面板做。
2. **配置清单**：管什么 / 默认 / 候选从哪来 / 选错怎样 / 按项目记 / 何时生效 / 怎么清。
3. **分流**：反复做且要动平台的 → 交给 agent；多步、长等、中途要人、失败要续的 → 封成一个动作（按钮 + 交给 agent 的入口）；
   只是看 → 只读。
4. **状态矩阵**：每态「看到什么 / 能做什么 / agent 能接着做什么」。

产出：ASCII 画面（卡片、设置面、每种状态）+ 状态矩阵（左列图号）+ 图例。

判据：

- 用户对着图确认过每种状态，或指出哪格不对。
- 每格是用户看得见或能操作的事，没有"系统内部会…"。
- 矩阵每个词都能在图例里指到屏幕；图例不能只是同义词。
- 每种缺失有一句可照做的话：缺什么、去哪补、谁补。
- 每个控件对应一句用户会对 agent 说的话，界面上有该句的位置。
- 真机造不出的状态也有设计。

## 步骤 2 — agent 能力

先问：

- 用户会怎么说这件事？agent 需要先知道什么？
- agent 做完，用户需要知道什么？
- 哪些是真动手、必须先点头？点头时要看到什么？

定五件事：

1. **能力清单**：每件事一句"agent 能做什么"；说明为何是独立的事，而不是某件事的选项。
2. **入参 / 返回**：贴真实调用（参数 JSON）与真实返回正文（照抄）。补默认值、上限（不悄悄截）、
   取值范围、给错怎么改。
3. **全场景**：正常 / 没有 / 分不清是哪一份（不许猜）/ 参数错 / 超上限 / 能力未装好 / 要登录或超时 /
   还有下一批 / 截断（说清截了什么、多少）/ 没有当前项目。
4. **写操作两拍**：先预览（说清将要做什么；画法见 [TOOLS.md](TOOLS.md) §5），再执行。预览让用户判断"要不要做"，不是"要不要允许"。
5. **点头范围**：改平台 / 改这台机器 / 改面板。点头时展示这次具体发生什么（对象、版本、环境）；
   说不清就不问，停下让 agent 去查。

产出：真实调用与返回，逐条贴出。能连平台就真跑；不能就用真实代码输出并标注样例。

判据：

- 每种情况有确定结果；拒绝文案带 agent 可执行的下一步。
- 入参与返回照抄；边界给真实报错原文。
- 分不清的那格不许猜、不许退回默认。
- 截断、越界、分页说清边界与下一批。
- 点头格写"会发生什么"，不写"这是什么操作"。
- 用户自按入口不点头，但与 agent 同一条链路、同一结果。

## 步骤 3 — 联动

先问：

- agent 改完，多久看到、哪一格变？
- agent 只读，面板是否变、变哪格？（口径 [LINKAGE.md](LINKAGE.md) §1）
- agent 跑几分钟时，用户看哪？
- 点"交给 agent"后，agent 拿到什么？

定五件事：

1. **何时变**：读这一格 → 该格按最窄切片重读，值与对话一致；读面板外的东西（明细 / 日志 / 子集）→ 不变；
   预览 → 不变；真写 → 该格新值；用户自按 → 立刻变。
2. **进行中**：显示到哪步；要登录给链接；失败给原因与原始输出。不画进度条、不画流程控制台。
3. **交给 agent 的内容**：哪一类、哪个对象、多少，加一句用哪个能力取明细。
4. **收起模块 = 该项目内 agent 也失去该能力**，开始时说明。
5. **不陈旧**：切项目、别的窗口在改、程序刚更新，三者要么实时要么说清。

产出："变之前 / 变之后"两张 ASCII + 联动表（何时变、哪格变）。

判据：

- 用户对着两张图看过一次真实变化。
- 每格说清"何时变、哪格变、看到什么"；"哪一格"细到"某投影 + 最窄参数"（`inventory/builds?env=dev`）。
- 面板不停在旧值；允许延迟但要说清。
- 每个"交给 agent"都说清 agent 收到的内容。
