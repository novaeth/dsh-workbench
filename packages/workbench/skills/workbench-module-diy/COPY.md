# 文案：先判读者

一块模块同时给三种人写字：卡片给人、工具描述给 agent、原始输出给开发者。判错读者，后面全错。

## 1 三类读者

| 读者 | 读什么 | 判据 |
|---|---|---|
| **agent** | 工具描述、参数说明、返回、错误、`reason` / `{blocked}`、中断通知、`context.render` | 读完知道下一次调什么 |
| **终端用户** | 卡片、空态、阻断、按钮、配置、审批屏、agent 的交代 | 读完知道点哪 / 要不要做，且不写代码 |
| **开发者** | 日志、`detail`、原始输出 | 排障时能对照、能检索 |

审批字段的归属容易混：

| 字段 | 读者 |
|---|---|
| `needsApproval.question` / `fallback`、`approvalDetail` / `approval.render`、`approval_note` | 终端用户 |
| `needsApproval.reason`（deny）、`{blocked}` | agent |

## 2 两层：主句 + 原文

同一处既有用户又有技术细节时，成对写：

- **主句**：给人，不含错误码、路径、堆栈、内部词。
- **原文**：给开发者，原样，放 `detail` / 折叠区 / 日志。

两条判据：

1. 遮住原文只读主句：用户知道发生了什么、下一步做什么。
2. 遮住主句只读原文：开发能定位。

## 3 人侧

1. **可复述**：不写代码的人读完能说出下一步。
2. **名词看得见**：用界面上的词；`unit` / 套件 / 宿主 / schema / payload / 运行时 不进主句。
3. **一句一个意思**：不靠括号补解释，一句不放两个动作。
4. **不露空值**：读不到就说读不到，不写 `0` / `undefined` / `NaN` / 裸键名。

状态四义、时间写相对时间、单位跟数字：见 [PANEL.md](PANEL.md) §7。
审批那一屏的写法：见 [DESIGN.md](DESIGN.md) §3 —— 标题一句，事实进详情，明细一行一个事实。
中文与英文都写；英文重写，不直译。

## 4 agent 侧

**agent 自己推得出的，不写。** 工具名、参数名、schema、上一次返回已经说了的，不重复第二遍。

- 删：字段清单、枚举释义、参数名复述、理由、输出里已有的话。
- 留：写与危险、跨工具下一步与字面量、非显然的默认与上限、会误导的坑、安全事实。
- 描述：一句“是什么” + 一句“什么时候用”；不写“这个工具用于……”。
- 返回：事实 + 总数 / 分页 + 下一次调用；ID、版本、单位原样。
- 错误：发生了什么 + 能不能重试 + 下一步；不甩堆栈。
- 通知：自包含 —— 谁做了什么 + 哪件事变了 + 现在做什么。

加字先减字。模块工具的提示词没有字数闸，自己守。

## 5 开发侧

- **原文**：日志、堆栈、命令不翻译、不美化。
- **可检索**：保留错误码、路径、ID、时间戳。
- **不进主句**：这些内容用户能看到时，折叠并标注“原始输出 / 堆栈 / 命令”；主句不依赖它。

日志一行：目标 + 发生了什么 + 关键值原样。不写“出错了”这种没有定位信息的句子。

## 6 硬规则

- 读不到写读不到，不写 0。
- 主句只放人话；错误码、路径、堆栈、内部词放原文。
- 事实原样：ID、版本、单位、时间戳不改写、不四舍五入。
- 不引用不存在的工具、字段、页面、命令。
- 不写“系统内部错误 / 请稍候”这类没有信息的句子。

## 7 验

1. 真卡片：五态、两语各看一遍；`dsh-wb-module check --only cards` 抓 `undefined` / `NaN` / 裸键。
2. 遮住测试两条都过。
3. 工具：注册后读描述，逐句问“模型推得出来吗”；真调一次读返回；漏参数读报错。
4. 拿五个用户会说的话试：只凭描述能不能挑中这把工具。

## 8 例

| 面 | 改前 | 改后 |
|---|---|---|
| 空态 | 暂无数据 | 这个环境还没有构建记录。换一个环境，或先跑一次构建。 |
| 阻断 | 系统内部错误，请稍后重试 | 这次没读到发布记录。检查网络后重试。 |
| 按钮 | 确定 | 发布到生产 |
| 描述 | 用于查看构建状态的工具 | 看某个环境最近一次构建：状态、耗时、提交；用户说“发布没成功”就先调它。 |
| 返回 | 操作成功 | 已发布 v1.2.3 到生产；下一步 `_build` 看结果。 |
| 拒绝 | 不允许 | 这个环境是生产；先在确认条上点「发布到生产」。 |
| 日志 | 出错了 | `[inventory] release v1.2.3 failed: HTTP 502 (retryable)` |
