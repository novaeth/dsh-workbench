# @dsh-workbench/module-hello

工作台里最小的可安装模块：安装后右侧多一张「示例模块」卡片，卸载后消失。

## 你会看到什么

右侧面板多一张「示例模块」卡片，标题下面两行说明文字。卡头有刷新按钮，但这个模块没有数据源，刷新只会重绘卡片。

## 安装

在工作台的「模块市场」里添加 `@dsh-workbench/module-hello`。工作台把它装成 profile 的
普通依赖，再在 profile 的 `cordis.patch.yml` 里写一行（`wb-hello`）把它挂上；它**不会**出现在
dsh 的插件页。安装后即启用，没有单独的开关。

安装完成后在右侧面板的「面板模块」里勾选「示例模块」，卡片才会出现。

## agent 能做什么

这个模块没有给 agent 开放工具，也没有写入通道；它只演示一张卡片如何接入外壳。

## 数据从哪来

没有数据源：卡片上的文字由模块自带，不读接口、不需要登录。

## 卸载

在模块市场卸载：工作台跑 `pnpm remove` 把包从 profile 拿掉，并删掉 `wb-hello` 那一行。
卸载后卡片消失，不影响其他模块。

## 出问题先看

卡片没有出现时，先确认当前项目的面板里已勾选「示例模块」；仍未出现就重新安装一次。
